# DWDM Orange Assignment - Diabetes Disease Progression

This repository documents nine Data Warehousing and Data Mining practicals completed with Orange Data Mining using the scikit-learn Diabetes dataset.

## Dataset

The dataset has 442 patient records, ten baseline features, and a numeric disease-progression target. A derived risk class labels records as high or low based on the median progression score.

## Practicals

1. Data Cleaning
2. Data Reduction
3. Data Transformation
4. Association Rules with Apriori
5. Statistical Analysis
6. Regression
7. Outlier Analysis
8. K-Means Clustering
9. Simple K-Means Evaluation

See the visible experiment guides in the datasets directory. Run datasets/prepare_diabetes_exports.py to recreate the CSV inputs from scikit-learn.
